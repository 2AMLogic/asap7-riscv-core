# Block manifest and tier-verdict record

This directory holds this block's `klt signoff` input and its committed
output: the machine-readable gap-to-T1 record. Tier grades are predicted-model
tool results; nothing here implies fabrication.

## Files

- **`asap7-riscv-core.json`** — block manifest: `block: asap7-riscv-core`,
  `kind: digital`, and an empty `evidence` map. No T1 item cites evidence yet,
  so the record grades every item unmet. Add citations here as evidence lands.
- **`asap7-riscv-core.signoff.json`** — verdict of record, generated by
  `klt signoff` (never hand-edited).
- **`design-evidence-tiers.md`** — the T1 checklist doc, vendored
  byte-identical from `docs/design-evidence-tiers.md` in
  [2AMLogic/klayout-tools](https://github.com/2AMLogic/klayout-tools) at commit
  `e88f211fa485959b382e2596c86648ce4e66ea78`.

## Pins

- `klayout-tools==0.7.0` (here and in `.github/workflows/signoff.yml`). A
  floating version would let the byte-compare drift.

## Regenerate the record

```sh
uvx --from "klayout-tools==0.7.0" klt signoff \
    --manifest manifests/asap7-riscv-core.json \
    --tiers-doc manifests/design-evidence-tiers.md \
    --format json > manifests/asap7-riscv-core.signoff.json
```

Exit 0 (all T1 items met) or 3 (at least one unmet) are both valid.
`.github/workflows/signoff.yml` re-runs this and fails if the output differs
from the committed record.
