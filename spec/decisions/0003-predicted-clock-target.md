# 0003 — Predicted clock target

**Status:** accepted 2026-10-17.

**Decision.** 1 GHz predicted, post-route STA at the SS corner (0.63 V / 100 °C, `spec/core.md`),
is the target. 500 MHz is the fallback; 1.5 GHz is the stretch. These are predicted figures against
a predictive model; the block is never fabricated and no frequency is measured.

**Why.** Carried from the README draft; the corner is now named so the figure is reproducible.
