# 0004 — Floorplan starting values

**Status:** accepted 2026-10-17 as starting values.

**Decision.** Core utilisation 60 %, aspect ratio 1.0, single block, no SRAM or macros.

**Why.** No placement evidence exists yet, so these are conventional, conservative starting values
for an unmodified mid-sized core, not a result. Rejected: tuning utilisation before a routed run
exists. A later record may change them given routed congestion and timing data.
